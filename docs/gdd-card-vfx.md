# GDD: カード使用演出（Card VFX）

- 版: v0.1（2026-09-29）草案
- 担当: 設計 Claude Code／実装 Codex（演出シーン・素材）、Claude Code（`cards.gd` の `vfx` 割り当て）
- 手本: 「触手」`tentacle_ground`（`scenes/combat/TentacleStrike.gd`）と「火球」`fireball`（`scenes/combat/FireballShot.gd`）
- 対象: プレイヤーが使えるカード68枚（状態異常7枚と `test_black_sheep` は除く）＋敵が使うカード20枚

## 1. 目的
カードを使ったときの手応えを、イラスト・カード名・効果の3つから一目で結びつける。
「触手」は敵の足元から触手が生えて叩き、「火球」は手元から火の玉が飛んで着弾する。どちらも**イラストに描かれたものが、そのまま戦場に出てきて効果を起こす**。この考え方を全カードに広げる。

## 2. 現状
| `vfx` | 見た目 | 付いているカード |
|---|---|---|
| `impact` | 敵の中心に衝撃のスプライト | 15枚（汎用。イラストとは無関係） |
| `slash` | 敵の中心に斬撃のスプライト | つじ風×2・ムラマサ・なまくら |
| `arrow` | 手元から矢が飛ぶ | クロスボウ・風神の弓 |
| `fireball` | 火の玉が飛んで着弾、着弾まで数字とSEを遅らせる | 火球 |
| `tentacle_ground` | 足元から触手が生えて叩く、叩くまで数字とSEを遅らせる | 触手 |
| （なし） | 何も出ない | 残りの攻撃カード（光の柱、呼び声など）と、スキル・パワーの全部 |

- スキルとパワーには演出がない。音も共通の `skill` だけ。
- 敵がカードを使ったときは、共通の被弾フラッシュ（`_fx_player_hurt`）と盾（`_fx_shield`）しか出ない。

## 3. 共通ルール
1. **イラストの主役を動かす。** 新しい絵を考えるより、カードのイラストにいるもの（猫の手、三叉の矛、黒羊、鐘…）を戦場に出す。
2. **当たる瞬間に数字と音を合わせる。** 触手・火球と同じく、`struck` シグナルが来るまでダメージ数字と被弾SEを待たせる（`_arm_tentacle_hit_hold` の仕組みを共通化する）。保険のタイムアウトも同じように付ける。
3. **尺の上限**: 攻撃は使ってから当たるまで0.45秒以内、全体の終わりまで0.9秒以内。スキルは0.6秒以内。連打しても次のカードの操作を止めない（入力はロックしない）。
4. **ドット絵のまま描く。** 素材は原寸で描き、3倍 nearest で拡大する。回転・拡大縮小は整数倍を基本にする。ぼかしや歪みのシェーダーは使わない（`gdd-sanity-fx.md` と同じ方針）。
5. **重ね順**: 攻撃演出は `VfxLayer` の `z_index = -2`（敵の前、ダメージ数字の後ろ）。自分側の演出は手札より下、HUDより下。
6. **全体攻撃**は、1体ずつ同じ演出を出すのではなく「1つの大きな現象が全体をなめる」形を優先する（例：つじ風は1本の竜巻が横切る）。数字は現象が各敵に届いた順に出す。
7. **「揺れ・歪みを減らす」がオンのとき**: 飛翔・伸長・画面フラッシュは省略し、着弾コマ（または着弾スプライト1枚）だけを0.2秒出す。数字とSEは待たずにすぐ出す（今の触手・火球と同じ扱い）。画面全体のフラッシュは出さない。
8. **属性の色**（演出の芯・縁の基準）

| 属性 | 芯 | 縁・余韻 |
|---|---|---|
| 旧神 elder | `#FFE6A0` 金白 | `#C89A3C` |
| 水 water | `#BFF3FF` | `#2A7C9C` |
| 風 wind | `#F2FFF8` | `#7EC6B6` |
| 火 fire | `#FFF2A8` | `#E0501E` |
| 地・豊穣 earth | `#E8E09A` | `#6E7A2E` |
| 騎士 knight | `#E8ECF2` 鋼 | `#7A8496` |
| 魔術 magic | `#B8FFF0` | `#3AA6A0` |
| 外なる神 outer | `#F0C8FF` | `#7A3CB0` |
| 全 all | 虹（7色を1コマずつ巡回） | `#FFFFFF` |

## 4. 演出の型（部品）
カードごとに1から作らず、下の型に素材とパラメータを差し込む。`cards.gd` の `vfx` には「型の名前」ではなく「カード固有のキー」を入れ、`Combat.gd` 側の表でキー → 型＋素材に解決する（素材が無いうちは型の既定素材で出せる）。

### 4.1 敵に向かう型
| 型 | 動き | 既存の元 | 使うカードの例 |
|---|---|---|---|
| `projectile` | 手元（手札の上）から飛んで着弾、着弾で火花 | FireballShot | 火球、残響 |
| `ground_rise` | 敵の足元から生える → 叩く／噴き上がる | TentacleStrike | 触手、冷たい炎、大地震 |
| `sky_fall` | 画面上端から敵へ一直線に落ちる柱・物体 | 新規 | 光の柱、寝返り |
| `thrust` | 画面下（プレイヤー側）から敵へ突き上がる武器 | 新規 | 三叉の矛、最期の抵抗 |
| `stamp` | 敵の上に大きく現れて振り下ろす（爪・刃） | slash を発展 | ねこの手、ムラマサ、なまくら |
| `sweep` | 画面の端から端へ1つの現象が横切り、通過した敵に当たる | 新規 | つじ風、風神の弓 |
| `rush` | 画面左の外から物体が突進して敵にぶつかる | 新規 | 突進 |
| `ring_wave` | 1点から同心円が広がり、届いた敵に当たる | 新規 | いびき、呼び声、地磁気 |
| `volley` | 複数の弾が少しずつずれて飛ぶ | arrow を発展 | クロスボウ |
| `screen_burst` | 画面中央に集まる → 全画面の閃光 → 全敵に一斉着弾 | 新規 | 崩壊、究極魔術 |

### 4.2 自分に向かう型（スキル・パワー）
自分の立ち絵はないので、自分への効果は**画面下の手札の帯とHUD**に出す。

| 型 | 動き | 使うカードの例 |
|---|---|---|
| `self_guard` | 手札の帯の前に属性色の障壁が張られる（既存の `_fx_shield` を色と形で差し替えられるようにする） | 鱗、盾、塩の外皮 |
| `self_heal` | 使ったカードの位置から光の粒がHPゲージへ吸い込まれる | 夢の癒し、滋養 |
| `self_power` | HUDの自分の枠が属性色に1回脈打ち、状態アイコンが跳ねる | 唱和の呪文、女神の加護 |
| `turn_aura` | 「このターン倍化」系。画面下の縁に属性色のオーラが残り、ターン終了で消える（効果中であることを示す） | 海契約、砂漠、フォーマルハウト |
| `seek` | 山札アイコンから、加わるカードの枚数だけ光の筋が手札へ飛ぶ（色は加わるカードの属性） | 猫叉、闇、黄衣の王、武器庫 |
| `draw_burst` | 山札アイコンが光り、カードが勢いよく配られる（既存のドロー演出に光を足す） | 彼方の導き、異本、銀の鍵 |
| `summon` | イラストの主役（黒羊・火球・ねこの手・竜巻）が小さく現れて手札に飛び込み、カードに変わる | 落とし子、炎の主、黄色の幻覚 |
| `energy` | エナジー表示に光が走り、数字が跳ねる | ビール瓶、全能、えら呼吸 |
| `sacrifice` | 捨てる／消滅させるカードが手札から浮き、属性色の炎で燃えて消える | 炎契約、滋養（黒羊を消す）、究極魔術 |

### 4.3 敵が使うときの型
敵がカードを使うときは、**敵の位置 → 画面下（プレイヤー側）**に向きを反転して、同じ型を使う。着弾点は画面下中央（HPゲージの上）。着弾で `_fx_player_hurt` か `_fx_shield` を合わせる。

## 7. 実装の順番
1. **共通化**（Claude Code）: 当たるまで数字とSEを待たせる仕組み（`_arm_tentacle_hit_hold` と2つのタイムアウト）を、全部の型で使える1つの入口にまとめる。スキルでも `vfx` を読むようにする。
2. **型の土台**（Codex）: `sky_fall` `thrust` `stamp` `sweep` `ring_wave` を、TentacleStrike／FireballShot と同じ「横1列のシート＋`struck`」の形で作る。
3. **優先度Aの素材**（Codex）: 光の柱、三叉の矛、ねこの手、つじ風、風神の弓、ムラマサ、冷たい炎、大地震、突進、呼び声、崩壊、究極魔術。
4. **自分側の型**（Codex）: `self_guard` `self_heal` `seek` `summon` `turn_aura`。
5. **敵側**: 型を反転して付ける。
6. 残りの優先度B・C。

## 8. 決めていないこと
- 1ターンに同じカードを連打したとき（火球×3など）に演出を重ねるか、間引くか。今の火球は重ねている。
- `turn_aura` を複数同時に出すときの並べ方（海契約と砂漠を同じターンに使った場合など）。
- 敵側の演出を、敵の行動予告にも小さく出すかどうか。
