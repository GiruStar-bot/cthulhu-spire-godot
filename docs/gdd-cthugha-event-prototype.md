# クトゥグァイベント試作 v0.4

更新日: 2026-09-29

## 目的とプレイヤー体験

大司祭から教わった星の名を合言葉として狂信者へ伝え、奥の会話へ進む三段階イベント。合言葉の入力本文は判定にだけ使い、保存しない。選択の結果は次の遭遇と世界周期に残る。

## 入力と出力

| 段階 | 入力 | 出力 |
| --- | --- | --- |
| ① 大司祭 | 「はい」 | 所持カードと現在のランデッキに火球3枚、次回は② |
| ① 大司祭 | 「いいえ」 | Dream Islandから場面1へ戻るまで抽選停止 |
| ② 狂信者 | 「いいえ」 | 同周期の抽選停止 |
| ② 狂信者 | 「はい」→合言葉「フォーマルハウト」 | 次回は③ |
| ② 狂信者 | 「答えない」 | 次回は① |
| ② 狂信者 | 合言葉の誤答・空欄 | 「何いってんだ？」から狂信者戦。その潜航中は再出現せず、次の潜航から① |
| ③ 三人 | 勧誘を断る選択肢 | 同周期の抽選停止 |
| ③ 三人 | 最後まで「思う」 | 体力・正気度0、既存の正気度0と同じプロフィール初期化、Dream Islandへ |

進捗はプロフィールに保存し、通常のラン終了では消えない。Dream Islandを経て場面1のタイトルから始めた時に①へ戻す。既存のDreamGateの「上」選択が通常世界へ戻す経路。

## 例外と失敗状態

- 合言葉は①で大司祭が教える星の名「フォーマルハウト」。②ではカタカナ・ひらがな・原語 `Fomalhaut` を受け付ける。入力本文は保存しない。
- 空欄や誤答は狂信者戦に入る。「答えない」で入力を回避できる。
- 狂信者戦は既存の戦闘報酬・敗北処理に従う。勝利しても進捗は①へ戻り、その潜航中は抽選から除外する。次の潜航開始で除外を解除する。
- 旧セーブにクトゥグァの項目がない場合は①から開始する。
- 正気度0エンドはプロフィール全消去を伴う。最終選択の重さをプレイテストで確認する。

## 調整項目と検証

- 予兆イベントでの出現比率は既存のアイホートと1対1 `[PLACEHOLDER]`。
- 入力上限32文字。合言葉の手がかりの分かりやすさはプレイテストで調整する。
- 火球3枚は企画文書の指定値。既存カードは使用後に消滅するため、報酬としての価値を確認する。
- 狂信者・侍祭・大司祭の抽選に既存の「火球」と「炎の吸血」（企画上の「火の吸血」に対応）を追加する。
- 破綻の目安: 進捗が逆戻りする、除外後に再抽選される、入力文が保存される、三人の会話やボタンが画面外へ出る。

## 会話と画面の表示規則

- キャラクターは `Enemies` の `sprite` から戦闘用の `enemies_px/*_body_1.png` を読み、待機コマ0と1を交互に表示する。旧立ち絵は使わない。
- shrineの床を足元に、③では左から狂信者・大司祭・侍祭を並べる。
- 台詞は企画文書の鍵かっこ一組を一つの発話として順番に再生する。同じ人物の連続発話も結合しない。
- 画面下部3分の1を占める薄黒い会話パネルの左上に話者名、下に台詞を表示する。既存の文字送り音を使い、発話が終わるまで次の台詞・選択肢は出さない。追加の立ち絵は置かない。
- 現在の話者は明るく、他のキャラクターは暗く表示する。パネルはキャラクターの手前に重ねる。
- 観察基準: ③の冒頭で大司祭→侍祭→大司祭→大司祭の順に話者名と明るいキャラクターが切り替わり、最後の質問後に初めて選択肢が出る。

## 変更履歴

- v0.1: 三段階の分岐、入力分類、戦闘遷移、周期をまたぐ保存、みなみのうお座の仮演出を追加。
- v0.2: 立ち絵を戦闘用ドット絵へ変更。共通の吹き出しと文字送り音を使い、台詞を話者ごと・鍵かっこごとに逐次再生。
- v0.3: 複数人の視認性を優先し、吹き出しを下部の固定会話パネルに変更。話者名とキャラクターの明暗で発話者を示す。
- v0.4: ②の自由入力を星の名の合言葉に変更。誤答による戦闘後は次の潜航まで抽選停止。③冒頭の狂信者の苦労についての台詞を削除。

合言葉の由来: August Derleth「[The Dweller in Darkness](https://www.scribd.com/document/750139872/TheDwellerInDarkness)」(Weird Tales, November 1944) のクトゥグァ召喚句に Fomalhaut が登場する。ゲーム内では長い呪文を要求せず、星の名だけを使う。
