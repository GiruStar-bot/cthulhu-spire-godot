# ムーの蛇人：ドット敵アニメーション

元の `art/pixel/serpent.png` を基に、112×168px・48色のドット絵として `idle.png` を描き直した。`idle_b.png` は尾の輪を少し締めた待機差分。`prepare.png` は肩から腕を寄せて胸飾りを囲み、`release.png` は尾を地面に置いたまま腕と襟を広げる全身キーポーズ。制作画像は `.gdignore` でGodotのインポート対象から除外する。

`python tools/build_serpent_sheets.py` で本体・効果シートとプレビューを再生成する。本体は112×168pxを横に11枚、効果は112×216pxを横に11枚。各コマを元の全身キーポーズから組み、48色の共通パレット、二値透過、整数ピクセルに揃える。

| コマ | 動作 |
| --- | --- |
| 0–2 | 尾が地面に接したまま締まり、上体と襟が控えめに追従する |
| 3–4 | 両腕が胸飾りに集まり、金と水色の流れが輪を作り始める |
| 5 | 尾を締めて腕を開き、水の輪を広げる |
| 6 | 胸飾りからカードが現れ、金色の目・戦闘効果・実カード表示が一致する |
| 7–9 | カードが頭上へ上がり、水の輪がほどける |
| 10 | カードが分散し、待機に戻る |

カード画素は実装済みの狂信者の効果シートを再利用する。`cast_fire` は6。`serpent_fire_preview.png` は発動コマの拡大画像。
