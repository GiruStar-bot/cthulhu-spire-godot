# 星から来た色：浮遊・繭のドットアニメーション

元の `art/pixel/colour.png` を基に、112×168px・64色のドット絵として `idle.png` を描き直した。`weave.png` は胸の前を空けて両腕と糸状の触手を寄せた姿勢、`burst.png` は繭が弾けた反動の姿勢。制作画像は `.gdignore` でGodotのインポート対象から外す。

`python tools/build_colour_sheets.py` で本体・効果シートとプレビューを再生成する。本体は112×168pxを横に16枚、効果は112×216pxを横に16枚。輪郭と陰影を保ったまま緑・青・紫の広い色帯を位相をずらして6コマに描く。戦闘側の既存浮遊Tweenも有効にし、上下の漂いと体内の色のうねりを重ねる。従来の敵は2コマ待機のままで、この敵だけ6コマを0.20秒間隔で循環する。

| コマ | 動作 |
| --- | --- |
| 0–5 | 浮遊中、体内の色帯が流れる待機ループ |
| 6–7 | 両手・胸から細い触手を伸ばす |
| 8 | 胸の前で繭を編み始める |
| 9–10 | 虹色の糸が交差した繭が閉じ、亀裂が走る |
| 11 | 繭が弾けてカードが現れる。戦闘効果と実カード表示が始まる |
| 12–14 | カードが頭上へ上がる |
| 15 | カードが粒に分散し、待機に戻る |

カード画素は実装済みの狂信者の効果シートから再利用する。`cast_fire` は11。`colour_cocoon_preview.png` と `colour_fire_preview.png` は重要コマの拡大画像。
