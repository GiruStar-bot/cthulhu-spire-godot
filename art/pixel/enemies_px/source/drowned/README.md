# 溺れた眷属：ドット敵アニメーション制作メモ

`art/pixel/drowned.png` を参照して作った4枚の透過キーポーズから、`tools/build_drowned_sheets.ps1` でゲーム用シートを生成する。Godot が読むのは親ディレクトリの `drowned_body_1.png` と `drowned_fx_1.png`。このソースディレクトリは `.gdignore` で Godot のインポート対象から外している。

| 本体コマ | ポーズ | 用途 |
| --- | --- | --- |
| 0–1 | idle | 待機。1は全身を1px上げる |
| 2 | idle | 動作開始 |
| 3 | early | 肩から二の腕を動かし、手は腹の横 |
| 4 | mid | 手を腹の前に寄せる |
| 5 | cast | 胸元に小さな予兆の光 |
| 6 | cast | 既存3体と同じ金色と青緑のカードが胸元に現れ、目の点灯と戦闘効果が一致 |
| 7 | mid | カードを縦向きにして頭の上へ移動 |
| 8 | early | カードが頭上に到達 |
| 9 | idle | カードが粒に分散して消える |

本体は112×168pxを横に10枚、効果は112×216pxを横に10枚。顔や衣服の陰影を回転・シアー変形しないため、全身の差し替えコマを使う。各コマは元のキーポーズから描き直し、前コマを下地に重ねない。生成後は48色の共通パレットと二値透過に整える。効果には大司祭の予兆と狂信者のカード・分散画素を再利用し、既存3体の視覚言語に合わせる。`cast_fire` は6で、目の点灯・カード出現と一致させる。

`python tools/preview_drowned.py` は4倍表示の `drowned_preview.gif` と発動コマの `drowned_fire_preview.png` を作る。ソース画像とプレビューは制作資料であり、ゲームでは使用しない。

これはキーポーズ差し替え式のコマアニメーションで、個別パーツを実行時に回転させる骨格リグではない。別の身振りを増やす場合は、肩・二の腕・肘・前腕・手の順で新たなポーズを描き、全コマの継ぎ目と輪郭を確認する。
