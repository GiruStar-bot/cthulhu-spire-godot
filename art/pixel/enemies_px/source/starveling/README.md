# 飢えし仔：ドット敵アニメーション

元の `art/pixel/starveling.png` を基に、112×168px・48色のクラシックなドット絵として `idle.png` を描き直した。`inhale.png` と `release.png` は肩・上腕・肘・手首まで描き直した全身の差し替えキーポーズ。制作画像は `.gdignore` でGodotのインポート対象から除外する。

`python tools/build_starveling_sheets.py` で本体・効果シートとプレビューを再生成する。本体は112×168pxを横に11枚、効果は112×216pxを横に11枚。48色の共通パレット、二値透過、整数ピクセルで書き出す。

| コマ | 動作 |
| --- | --- |
| 0–2 | 待機、軽い呼吸 |
| 3–4 | 体を縮め、肩から腕を引いて水を吸い込む |
| 5 | 口から水と水泡を吐き、胸の前でカード形に集まる |
| 6 | 水泡がカードに変化。戦闘効果と実カードの表示が始まる |
| 7–9 | カードが頭上に上がる |
| 10 | カードが分散し、待機に戻る |

カードの画素は実装済みの狂信者の効果シートから再利用する。`cast_fire` は6で、水泡からカードへの変化と戦闘側の実カード表示に合わせる。
