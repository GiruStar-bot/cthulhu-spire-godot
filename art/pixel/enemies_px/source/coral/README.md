# 礁の衛士：ドット敵アニメーション

元の `art/pixel/coral.png` を基に、溺れた眷属と同じ112×168px・48色のクラシックなドット絵として `idle.png` を描き直した。`raised.png` と `impact.png` はこの新しいベースに合わせた全身の差し替えキーポーズ。大型画像は制作資料で、Godotには `.gdignore` により読み込ませない。

各キーポーズの顔と瞳は真正面に揃え、プレイヤーを見据え続ける。矛を構えて打ち下ろす間も視線は外さない。

`python tools/build_coral_sheets.py` で `coral_body_1.png` と `coral_fx_1.png` を再生成する。各フレームは元のキーポーズから合成し、最終的に48色・二値透過・整数ピクセルへ揃える。カード画素は実装済みの狂信者のシートから再利用する。

| コマ | 動作 |
| --- | --- |
| 0–2 | 何も持たずに待機・呼吸 |
| 3 | 手に三叉の矛が出現する |
| 4–5 | 穂先を上向きに構え、石突きを地面から持ち上げる |
| 6 | **石突き**を地面に打つ。水色の衝撃、胸元のカード、効果発動が一致する |
| 7–9 | 水波が広がり、カードが頭上へ上がる |
| 10 | カードと矛が粒に分散し、待機姿勢に戻る |

本体は112×168pxを横に11枚、効果は112×216pxを横に11枚。`cast_fire` は6。矛の穂先を地面に突く演出ではない。
